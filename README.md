# Distance Vector Routing - Minimal Scaffold

This is a barebones folder structure so your team can write all code yourselves.

## Folders
- `src/dv/` — put your Python modules here (CLI, networking, routing, topology).
- `topologies/` — put your topology files here.
- `docs/` — optional notes (roles, decisions).

## Suggested branches (create on GitHub)
- feature/networking
- feature/dv-core
- feature/cli-commands
- feature/topology-tests

## Run (later, once you add code)
```bash
python -m dv.cli -t topologies/sample_topology.txt -i 5
```
